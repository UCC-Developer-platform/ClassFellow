## 2. Approved Technical Caveats & Engineering Rules

1. **DPI Initialization Guard**: CustomTkinter handles DPI internally on startup. Any explicit call to `SetProcessDpiAwareness(2)` must be wrapped in a `try...except Exception: pass` block to prevent `E_ACCESSDENIED` crashes on Windows 11.
2. **Offline Schema Migration Mechanism**: Because school computers operate without internet-driven DB admin tools, `database.py` must track migration states via `PRAGMA user_version` (or a `schema_migrations` table) and auto-apply missing DDL scripts at startup.
3. **Native SQLite Online Backup API**: Never copy active SQLite WAL files via raw `shutil.copy2`. All daily and USB backup routines must invoke `src_conn.backup(dest_conn)`.
4. **Strict Financial Ledger Foreign Key Rule**: Invoices cannot be orphaned or deleted if a payment receipt exists. All payment tables enforce `FOREIGN KEY (invoice_id) REFERENCES fee_invoices(id) ON DELETE RESTRICT`.
